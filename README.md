# Automated Alpha: Q3 2026 earnings

Live: https://automatedalpha-earnings.vercel.app

`python3 season.py build` pulls company earnings releases from SEC EDGAR, extracts quoted revenue and EPS with Gemini, checks the year-ago revenue against available XBRL history, and renders `out/season.html`. Exact source quotes and units are required. A changed historical comparison suppresses acceleration until the bases are reconciled. Unresolved results are withheld with a reason; that does not imply a company error.

Completed-report consensus comes from MarketBeat’s dated earnings tables (Fiscal.ai data), matched to the issuer’s fiscal quarter and release date. The filing may follow the release by up to three days. Upcoming forecasts and the calendar use Finnhub. GAAP growth and consensus-comparable actuals are separate fields. Adjusted EPS actuals require a reviewed exact issuer quote bound to the filing and quarter; changed actuals stay blank until reconciled. Total/operating/adjusted revenue differences are labelled. Estimates are published rounded: an actual inside the stated rounding interval is inline, not a miss. Missing comparisons are excluded only from the affected percentage, with coverage displayed.

Yahoo supplies closing prices and indicative options quotes. Two-session price returns run from the last unaffected close through the second post-release session: report day starts session one for before-open reports; the following trading day starts session one for after-close reports. Five-session returns use the fifth session. Incomplete candles and ambiguous/date-only release times are excluded. Returns exclude dividends. `cache/market-evidence/` retains release timestamps, daily candles, underlying prices and option chains locally; `data/market-proof.json` retains the small input excerpts needed for offline replay. Options use the first expiry that includes the release; Friday after-close reports require a later expiry. The options expiry horizon differs from the two-session history.

The dashboard snapshot is generated October 24, 2026, using closing prices through October 23: 31 reported companies, one withheld (Bank of America). UnitedHealth’s revenue surprise is omitted because the provider actual does not reconcile at its published precision. GE’s total revenue includes insurance, while its consensus comparison uses separately quoted adjusted revenue. These are explicit basis decisions, not silent numerical overrides.

Needs Python 3.10+, Pillow, `FINNHUB_API_KEY` and `GEMINI_API_KEY`. Yahoo requests use curl. Run `python3 test_season.py` for extraction, semantic regressions and independent saved-snapshot replay; `python3 season.py render` opens the included snapshot without fresh provider calls. See `.cursor/skills/verify-earnings-desk/SKILL.md` for browser checks.

`.github/workflows/refresh.yml` schedules three weekday refreshes. It builds, verifies, deploys, then commits the deployed snapshot. GitHub needs a durable `VERCEL_TOKEN` scoped to the Evoa workspace and earnings project. A CLI login alone does not restore the scheduled job. Workspace and project IDs are fixed in the workflow; `VERCEL_PROJECT_ID` and `VERCEL_ORG_ID` can override CLI defaults.
